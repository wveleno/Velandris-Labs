VELANDRIS LABS — İŞ BİRLİĞİ FORMU BİLDİRİM DÜZELTMESİ

Bu pakette yalnızca güncellenmiş index.html vardır.

Kurulum:
1. GitHub reposunda kök dizindeki index.html dosyasını açın.
2. Bu paketteki index.html içeriğiyle değiştirin.
3. Commit changes yapın.
4. Siteyi açıp Ctrl+F5 ile yenileyin.

app.js, style.css, config.js ve worker klasörüne dokunmayın.

Form gönderildiğinde Web3Forms başarılı yanıt verirse yeşil tikli küçük bir bildirim açılır.
Hata durumunda kırmızı tonlu bir bildirim gösterilir. Bildirim birkaç saniye sonra kapanır.
Bu değişiklik kodda doğrulanmıştır; canlı e-posta teslimi ayrıca test edilmelidir.
