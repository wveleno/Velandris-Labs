VELANDRIS LABS — ÜCRETSİZ PROGRAMLAR BÖLÜMÜ

Bu paket mevcut siteye Ücretsiz Programlar bölümünü eklemek için gereken DEĞİŞEN DOSYALARI içerir.

Paket içeriği:
- index.html      Güncel ana sayfa + menüde yeni bağlantı + ana sayfa tanıtım alanı
- style.css       Ana sayfa bölümü ve program katalog sayfası stilleri
- programlar.html Yeni, ayrı program kataloğu sayfası

GitHub'a yükleme:
1. Bu ZIP'i bilgisayarında çıkar.
2. GitHub'daki Velandris-Labs deposunun kök dizininde bulunan index.html ve style.css dosyalarını bu pakettekilerle değiştir.
3. programlar.html dosyasını aynı kök dizine yeni dosya olarak ekle.
4. Commit changes yap.
5. Yayınlandıktan sonra https://wveleno.github.io/Velandris-Labs/ adresini Ctrl+F5 ile yenile.
6. Menüden Ücretsiz Programlar'a girildiğini ve formun hâlâ durduğunu kontrol et.

ÖNEMLİ:
- app.js, config.js, assets/ ve worker/ dosyalarını değiştirmeyin.
- Katalog şu an boş bir yayın durumu gösterir; gerçekte hazır olmayan programlar için indirme düğmesi veya sahte bağlantı yoktur.
- Bu paketi GitHub'a kendim yüklemedim. Dosyaların canlıya yansıması için yukarıdaki adımları sizin yapmanız gerekir.
